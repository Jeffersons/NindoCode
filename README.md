# NindoCode

NindoCode is an open source iOS app focused on helping developers study programming through multiple choice quizzes. The goal is to offer a simple and practical way to review concepts related to Swift, iOS, architecture, algorithms, data structures and general computer science topics.

## Features

- Multiple choice quizzes
- Instant feedback for each answer
- Clean and simple UI
- Easy to extend question sets
- Open source and community friendly

## Tech Stack

- Swift
- SwiftUI
- Xcode

## Roadmap

- Add difficulty levels
- Add offline question packs
